     Context

     The roadmap's last foundation item: a queryable simulation graph of typed
     nodes and edges,
     harvested from relations that already exist implicitly in the sim (parent
     hierarchy, Roche
     feeding, tidal disruption, lifecycle/supernova/merge events). It becomes
     the backbone for
     stellar evolution coupling, orbit prediction, galaxy formation, and
     timeline scrubbing.
     Follows the established cosmic_field / radiance_field module pattern
     (init/rebuild/
     tick/shutdown, main-thread only, HUD-free consumers + headless stdout
     verification).

     Scope decided with user: stored GRAVITY + GAS_FLOW edges, lazy RADIATION
     queries, a
     256-entry event ring buffer (groundwork for §6.3 timeline), Inspect-panel
     "Relations"
     consumer, and headless prints. No 3D overlay, no galaxy nodes yet.

     src/build.c

     Design keystones (verified against source)

     - Notify hooks all fire on the main thread: warmup's OMP region runs only
     physics_respa_* + trails; collision/lifecycle/supernova/accretion run in
     the main loop.
     - g_nbodies is high-water; slots are reused → events snapshot names at log
     time, and
     field_graph_body_events() matches index+name so a reused slot drops (not
     misattributes)
     old history. Match snapshot size to Body.name (check actual size in
     body.h).
     - Clocks: snapshot both g_sim_time (physics.h) and subject's Body.age_yr.
     - Edges heap-grown (16k-body universes; MAX_BODIES=128 is not the bound).
     RADIATION is
     never stored — O(bodies×emitters) — only queried lazily via
     radiance_field_top().

     cosmic_field_tick shape).

  The fix (src/universe.c, pass 2): Keplerian elements were converted
  heliocentrically (GM of the parent alone), and the center-of-mass correction
  then handed the parent a compensating velocity — inflating the pair's relative
  speed by (1+q). Harmless for planets (q ≲ 10⁻³), but the microquasar's donor
  is 0.67× its hole's mass, so its authored 0.15 AU orbit actually ran at ~0.8
  AU, outside the Roche lobe, and the shipped demo silently never transferred
  mass. Elements are now converted with the two-body GM = G·(M+m) and the body
  takes its barycentric velocity share M/(M+m), so the realized relative orbit
  matches the authored elements exactly.
